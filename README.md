# Differential Geometry and Vecotor Calculus

This repository contains implementations of some topics in differential geometry and vector calculus widely used in machine learning and quantum mechanics/computing. These topics are discussed in further detail on my [**blog**](https://morchalabi.github.io/MoriPages/Blog.html).

Current covered topics:
- Gradient descent-based optimization of right-circular cone function
- shape operator
- 2nd-order tansor (bilinear map)
- 4th-order tensor (multilinear map)
- 2nd-order Taylor approximation of Rosenbrock function
- Projection transport and Gaussian curvature
